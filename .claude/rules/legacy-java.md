# Legacy 1.12.2 code constraints

- Build: Unimined (Cleanroom fork), Gradle 9.8.0 on JDK 25, Java 25 source/bytecode, Cleanroom loader. Plain Forge / Java 8 is not a target (decision 2026-10-13). Do not upgrade the build further without approval.
- Mod dependencies go in `gradle/scripts/dependencies.gradle` using `modImplementation`/`modCompileOnly` (never plain `implementation` for mods). Local jars in `debugMod/` resolve via flatDir (`":name-without-.jar:"`).
- `Tags.java` is generated by Blossom from `src/main/java-templates`; `mcmod.info` from `src/main/resource-templates`. Edit the templates, not build output.
- Optional mods (Baubles, Metamorph, TiC, IC2, Mekanism, TOP) are soft dependencies. Guard with `intermod/` patterns; never hard-require them.
- Match surrounding style. Do not reformat files you are not changing.
- Phase 0-2: read only for gameplay code. Phase 3+: changes need an issue and a characterization test or documented manual verification first.
- Minecraft-independent logic is a future extraction candidate for the shared module; note candidates in `docs/porting/architecture/`, do not extract without approval.
